## 1. 列表 List

特点：元素可重复、有序、可修改、多类型。

```python
# 创建
nums = [1, 2, 3, 4, 5]
lst = list(range(5))       # [0, 1, 2, 3, 4]
```

### 1.1 增删查改

```python
# 访问
nums[0]          # 1
nums[-1]         # 5
nums[1:3]        # [2, 3]
nums[::-1]       # [5, 4, 3, 2, 1]

# 修改
nums[0] = 100

# 添加
nums.append(6)          # 末尾加
nums.insert(0, 0)       # 指定位置插
nums.extend([7, 8])     # 合并另一个列表
nums += [9, 10]         # 同 extend

# 删除
nums.remove(3)          # 按值删（只删第一个）
nums.pop()              # 删末尾并返回（有返回值）
nums.pop(0)             # 删指定索引
del nums[0]             # 按索引删
nums.clear()            # 清空

# 查找
nums.index(3)           # 返回索引，找不到报错
nums.count(3)           # 出现次数
3 in nums               # 是否存在
```

### 1.2 排序与反转

```python
# 排序
nums.sort()                  # 原地升序
nums.sort(reverse=True)      # 原地降序
nums.sort(key=abs)           # 按绝对值排

# 反转
nums.reverse()          # 原地反转（改原列表）
new = nums[::-1]        # 返回反转副本（不改原列表）
new = list(reversed(nums))

# nums[::-1] 原理：切片格式 [起:止:步]
# 起止都省略 = 取全部元素
# 步长 -1   = 从右往左取（反向）
# 组合 = 全部元素倒序 = 反转
# 例：[1,2,3,4,5][::-1] -> [5,4,3,2,1]
# 字符串同理："abc"[::-1] -> "cba"
# 注：切片一般规则是"左闭右开"（含起不含止），起止都省略时取全部
```

### 1.3 遍历与统计

```python
# 长度
len(nums)

# 遍历
for x in nums:
    print(x)

for i, x in enumerate(nums):   # 带索引
    print(i, x)

# 同时遍历多个
for a, b in zip([1, 2, 3], ["a", "b", "c"]):
    print(a, b)

# 统计
sum(nums); max(nums); min(nums); len(nums)

# 复制
nums2 = nums.copy()
nums2 = nums[:]
nums2 = list(nums)
```

### 1.4 解包

**解包**：把一个装有多个元素的"包裹"拆开，单独取出里面的元素。

```python
list1 = [1, 2, 5, 6, 7, 8]
list2 = [3, 44, 5, 5, 56]
combined = [*list1, *list2]
print(combined)   # [1, 2, 5, 6, 7, 8, 3, 44, 5, 5, 56]
# 不会去重，全部合并
```

### 1.5 列表推导式

**列表推导式**：用简洁的表达式快速创建新列表，结合迭代和条件筛选，一行完成遍历、转换、过滤。

**核心语法**：

```python
[expression for item in iterable if condition]
```

生成 0 到 4 的平方数列表：

```python
squares = [x**2 for x in range(5)]
print(squares)   # [0, 1, 4, 9, 16]

# 带条件筛选
squares = [x**2 for x in range(5) if x % 2 == 0]
print(squares)   # [0, 4, 16]
```

## 2. 字符串 Str

特点：**不可变性**（无法修改）、有序性、可迭代性。

### 2.1 索引与切片

```python
text = "Python"
print(text[0])    # P（正向索引从 0 开始）
print(text[-1])   # n（反向索引从 -1 开始）

# 切片
text = "Hello World"
print(text[0:5])    # Hello（索引 0 到 4，不包含右边）
print(text[6:])     # World（索引 6 到末尾）
print(text[::-1])   # dlroW olleH（反转字符串）

# text[x:y:z] 切片方向要一致
# x < y 时，z 必须为正数（正向取）；x > y 时，z 必须为负数（反向取）
# 方向冲突返回空，如 "hello"[0:5:-1] → ""
```

### 2.2 迭代遍历

字符串是可迭代对象，可直接用于 `for` 循环。

```python
for char in "ABC":
    print(char)
# A
# B
# C
```

### 2.3 成员判断

使用 `in` 或 `not in` 判断子串是否存在。

```python
sentence = "I love Python"
print("love" in sentence)      # True
print("Java" not in sentence)  # True
```

### 2.4 常用方法

```python
# find(sub) — 查找子串首次出现的位置，未找到返回 -1
text = "hello world"
print(text.find("o"))   # 4
print(text.find("x"))   # -1

# count(sub) — 统计子串出现次数（非重叠）
print(text.count("l"))  # 3
print(text.count("o"))  # 2

# upper() / lower() — 大小写转换
text = "Hello"
print(text.upper())  # HELLO
print(text.lower())  # hello

# split(sep) — 拆分为列表，默认按任意空白拆分
s = "a,b,c"
print(s.split(","))   # ['a', 'b', 'c']
s2 = "a  b   c"
print(s2.split())     # ['a', 'b', 'c']

# strip() — 去两端空白（默认空格、\n、\t），也可指定字符
text = "  hello  "
print(text.strip())   # hello
s = "***hi***"
print(s.strip("*"))   # hi

# replace(old, new) — 替换子串，可指定最大替换次数
text = "hello world"
print(text.replace("l", "x"))      # hexxo worxd
print(text.replace("l", "x", 2))   # hexxo world

# startswith(prefix) / endswith(suffix) — 判断开头/结尾，返回布尔值
text = "hello world"
print(text.startswith("he"))   # True
print(text.endswith("rld"))    # True
print(text.startswith("wo"))   # False
```

## 3. 元组 Tuple

特点：存储不同类型元素、元素可重复、有序、**不可修改**、可以嵌套 `(( ), ( ), ( ))`。

### 3.1 定义

```python
# 空元组
t1 = ()
t2 = tuple()
print(type(t1))   # <class 'tuple'>

# 带元素
t = (1, 2, 2, 3)

# 注意：单个元素必须加逗号，否则不是元组
t3 = (100)        # 这是 int，不是元组
t3 = (100,)       # 这才是元组
```

### 3.2 常用方法

| 方法       | 说明                              | 示例                       |
| ---------- | --------------------------------- | -------------------------- |
| `count(x)` | 统计元素 x 出现的次数             | `(1,2,2,3).count(2)` → `2` |
| `index(x)` | 返回第一个 x 的索引，不存在则报错 | `(1,2,3).index(3)` → `2`   |

```python
t = (1, 2, 2, 3)
print(t.count(2))   # 2
print(t.index(3))   # 3
```

### 3.3 组包与解包

- **组包**：多个值并到一个容器。
- **解包**：将容器解开成独立元素。

```python
# 基础组包
t1 = (1, 2, 3)

# 基础解包
a, b, c = (1, 2, 3)
a, b, c = t1
print(a, b, c)   # 1 2 3

# 星号解包：* 打包剩余元素（注意打包成列表）
first, *middle, last = (1, 2, 3, 4, 5)
print(first)    # 1
print(middle)   # [2, 3, 4]
print(last)     # 5

# 经典应用：交换两个变量的值（不用中间变量）
x, y = 10, 20
x, y = y, x     # 右侧实际是元组 (20, 10)
print(x, y)     # 20 10
```

### 3.4 案例：元组嵌套

```python
# 学生成绩表：姓名, 数学, 语文, 英语
students = (
    ("张三", 90, 85, 92),
    ("李四", 78, 88, 80),
    ("王五", 95, 92, 96),
    ("赵六", 92, 91, 93)
)

# 写法一：直接解包每个字段
print("平均分大于 90 的学生：")
for name, math, chinese, english in students:
    avg = (math + chinese + english) / 3
    if avg > 90:
        # {avg:.1f} 保留一位小数
        print(f"{name}: 数学{math}, 语文{chinese}, 英语{english} → 平均分 {avg:.1f}")

# 写法二：用索引取值
for s in students:
    avg = (s[1] + s[2] + s[3]) / 3
    if avg > 90:
        print(f"{s[0]}: 平均分 {avg:.1f}")
```

## 4. 集合 Set

特点：**无序**（不可通过索引访问）、**不可重复**（自动去重）、可修改。

### 4.1 定义

```python
# 定义集合
s1 = {1, 2, 3}
print(s1)   # {1, 2, 3}

# 空集合（注意不能用 {}，那是空字典）
empty_set = set()
print(type(empty_set))   # <class 'set'>

# 错误示范
# wrong = {}   # 这是字典，不是集合！
```

### 4.2 增删

```python
s = {1, 2, 3}

# 添加
s.add(4)                # {1, 2, 3, 4}
s.update([3, 5, 6])     # {1, 2, 3, 4, 5, 6}（3 已存在，不重复添加）

# 删指定元素
s.remove(1)             # {2, 3, 4, 5, 6}
# s.remove(10)          # 报错：KeyError
s.discard(10)           # 不报错，集合不变
s.discard(2)            # {3, 4, 5, 6}

# 随机弹出元素并返回
item = s.pop()
print(item)             # 3、4、5、6 中的任意一个

# 清空
s.clear()
print(s)                # set()
```

### 4.3 集合运算

```python
# union() — 并集：合并多个集合，自动去重，返回新集合
a = {1, 2, 3}
b = {3, 4, 5}
print(a.union(b))   # {1, 2, 3, 4, 5}
# 运算符写法：a | b（效果相同）

# intersection() — 交集：取共同存在的元素
a = {1, 2, 3}
b = {2, 3, 4}
print(a.intersection(b))   # {2, 3}
# 运算符写法：a & b（效果相同）

# difference() — 差集：在第一个集合但不在第二个集合中的元素
a = {1, 2, 3}
b = {2, 3, 4}
print(a.difference(b))     # {1}
print(b.difference(a))     # {4}
# 运算符写法：a - b
# difference() 可传入多个集合：a.difference(b, c)
```

## 5. 字典 Dict

特点：**可变**、**有序**（Python 3.7+ 按插入顺序）、以 **键值对（Key-Value）** 存储、**键不可重复**。

### 5.1 定义

```python
# 定义字典
student = {"name": "小明", "age": 18, "city": "北京"}

# 空字典（{} 是空字典，不是空集合）
empty_dict = {}
```

### 5.2 查（访问值）

```python
student = {"name": "小明", "age": 18}

# 方式一：直接通过键名（键不存在会报错 KeyError）
print(student["name"])   # 小明

# 方式二：使用 get()（键不存在返回 None 或默认值，更安全）
print(student.get("age"))          # 18
print(student.get("score", 0))     # 0（键不存在，返回默认值）
```

### 5.3 增与改

直接给键赋值：键不存在则新增，键已存在则覆盖。

```python
student = {"name": "小明"}
student["age"] = 18       # 新增键 "age"
student["name"] = "小红"  # 修改键 "name" 的值（覆盖）
print(student)            # {'name': '小红', 'age': 18}
```

### 5.4 删

```python
student = {"name": "小明", "age": 18, "city": "北京"}

# 方式一：del（删除指定键）
del student["age"]
print(student)   # {'name': '小明', 'city': '北京'}

# 方式二：pop（删除并返回被删除的值）
city = student.pop("city")
print(city)      # 北京
print(student)   # {'name': '小明'}

# 方式三：清空
student.clear()
print(student)   # {}
```

### 5.5 遍历

```python
student = {"name": "小明", "age": 18}

# 遍历所有的键
for key in student.keys():
    print(key)
# name
# age

# 遍历所有的值
for value in student.values():
    print(value)
# 小明
# 18

# 同时遍历键和值（最常用）
for key, value in student.items():
    print(f"{key}: {value}")
# name: 小明
# age: 18
```

## 6. 五大容器终极总结

> 包含：列表（List）、元组（Tuple）、集合（Set）、字典（Dict）、字符串（Str）

### 6.1 核心对比表

| 容器类型          | 定义语法   | 是否可变 | 是否有序       | 是否允许重复             | 元素/键要求                    | 是否支持索引           | 查询效率 | 典型使用场景                                   |
| :---------------- | :--------- | :------- | :------------- | :----------------------- | :----------------------------- | :--------------------- | :------- | :--------------------------------------------- |
| **列表（List）**  | `[1, 2]`   | ✅ 可变   | ✅ 有序         | ✅ 允许重复               | 无限制                         | ✅ 支持                 | O(n)     | 存储有序的、需要频繁增删改的序列               |
| **元组（Tuple）** | `(1, 2)`   | ❌ 不可变 | ✅ 有序         | ✅ 允许重复               | 无限制                         | ✅ 支持                 | O(n)     | 存储固定的、不可变的数据（如坐标、函数返回值） |
| **集合（Set）**   | `{1, 2}`   | ✅ 可变   | ❌ 无序         | ❌ **自动去重**           | 必须可哈希（不可变类型）       | ❌ 不支持               | O(1)     | 数据去重、数学集合运算（交并差）               |
| **字典（Dict）**  | `{"a": 1}` | ✅ 可变   | ✅ 有序（3.7+） | ❌ **键唯一**（值可重复） | **键**必须可哈希（不可变类型） | ❌ 不支持（通过键取值） | O(1)     | 存储键值对映射关系（如"姓名→成绩"）            |
| **字符串（Str）** | `"abc"`    | ❌ 不可变 | ✅ 有序         | ✅ 允许重复               | 只能存字符                     | ✅ 支持                 | O(n)     | 存储和操作文本数据                             |

### 6.2 核心本质记忆口诀

- **列表**：有序可变，什么都能装（瑞士军刀）。
- **元组**：有序不可变，定死不修改（身份证信息）。
- **集合**：无序不重复，交并差集强（去重神器）。
- **字典**：键值配对存，通过键查值（电话本）。
- **字符串**：不可变字符序列，专治文本（文字处理器）。

### 6.3 常用操作速记（增删查改）

| 操作     | 列表（List）                 | 元组（Tuple）    | 集合（Set）                        | 字典（Dict）            | 字符串（Str）                       |
| :------- | :--------------------------- | :--------------- | :--------------------------------- | :---------------------- | :---------------------------------- |
| **添加** | `append()` / `insert()`      | ❌ 不可添加       | `add()` / `update()`               | `d["新键"] = 值`        | ❌ 不可添加（用 `+` 拼接生成新串）   |
| **删除** | `del` / `pop()` / `remove()` | ❌ 不可删除       | `remove()` / `discard()` / `pop()` | `del` / `pop()`         | ❌ 不可删除（用 `replace` 生成新串） |
| **修改** | `lst[0] = 新值`              | ❌ 不可修改       | 先删再加                           | `d["旧键"] = 新值`      | ❌ 不可修改（用 `replace` 生成新串） |
| **查找** | `in` / `index()`             | `in` / `index()` | `in`                               | `d["键"]` / `get()`     | `in` / `find()` / `index()`         |
| **遍历** | `for i in lst:`              | `for i in t:`    | `for i in s:`                      | `for k,v in d.items():` | `for c in str:`                     |

### 6.4 容器之间的转换

```python
# 通用转换（均生成新对象）
lst = [1, 2, 2, 3]
t = tuple(lst)          # 列表 → 元组：(1, 2, 2, 3)
s = set(lst)            # 列表 → 集合：{1, 2, 3}（自动去重！）
lst2 = list(s)          # 集合 → 列表：[1, 2, 3]（顺序不保证）

# 字典特殊转换（需要成对的数据）
pairs = [("a", 1), ("b", 2)]
d = dict(pairs)         # 列表 → 字典：{"a": 1, "b": 2}
items = list(d.items()) # 字典 → 列表：[("a", 1), ("b", 2)]

# 字符串 ↔ 列表（最常用）
text = "hello"
chars = list(text)         # 字符串 → 列表：['h', 'e', 'l', 'l', 'o']
new_text = "".join(chars)  # 列表 → 字符串："hello"
```
