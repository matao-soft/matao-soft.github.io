## 1. 函数基础

### 1.1 什么是函数

**函数（Function）** 是组织好的、可重复使用的代码块，用于执行一个特定任务。接受输入（参数），进行处理，并可返回输出（返回值）。

使用函数的好处：提高代码的**复用性**、**可读性**、**模块化**。

### 1.2 定义与调用

```python
# 核心语法
def 函数名(参数1, 参数2, ...):
    """文档字符串（可选，说明函数作用）"""
    代码块
    return 返回值  # 没有 return 时，默认返回 None

# 调用
函数名(参数)
```

示例：

```python
def add(a, b):
    """返回两个数的和"""
    return a + b

result = add(3, 5)
print(result)   # 8
```

### 1.3 return 多返回值

Python 函数 `return` 多个值时，本质返回一个**元组**，可直接解包接收。

```python
def calc(a, b):
    return a + b, a - b, a * b, a / b

# 直接解包
sm, diff, prod, div = calc(10, 3)
print(sm, diff, prod, div)   # 13 7 30 3.33333...

# 接成元组
result = calc(10, 3)
print(result)   # (13, 7, 30, 3.3333...)
```

不写 `return` 或只写 `return` 时，函数返回 `None`：

```python
def say_hi(name):
    print(f"Hi, {name}")

print(say_hi("Tom"))   # 先打印 Hi, Tom；再打印 None
```

### 1.4 两个内置函数速记

```python
# round(x, y) — 对 x 四舍五入保留 y 位小数
print(round(3.14159, 2))   # 3.14
print(round(3.14159, 3))   # 3.142

# 字符串格式化（也是在函数笔记里常见的写法）
print(f"{3.14159:.2f}")    # 3.14（f-string 保留 2 位小数）
```

## 2. 参数传递的四种方式

### 2.1 位置参数（Positional Arguments）

按函数定义时参数的**顺序**依次传入，顺序和数量必须严格对应。

```python
def introduce(name, age, city):
    print(f"{name}, {age}岁, 来自{city}")

# 按顺序传入
introduce("小明", 18, "北京")
# 输出：小明, 18岁, 来自北京
```

### 2.2 关键字参数（Keyword Arguments）

调用时使用 `形参名 = 值` 的形式，可以打乱顺序，可读性更好。

```python
def introduce(name, age, city):
    print(f"{name}, {age}岁, 来自{city}")

introduce(city="上海", name="小红", age=20)
# 输出：小红, 20岁, 来自上海
```

### 2.3 位置参数 + 关键字参数混用

**规则：位置参数必须写在关键字参数之前**，否则报错。

```python
def introduce(name, age, city):
    print(f"{name}, {age}岁, 来自{city}")

# ✅ 正确：位置参数在前
introduce("小刚", city="广州", age=19)
# 输出：小刚, 19岁, 来自广州

# ❌ 错误：位置参数在关键字参数之后 → SyntaxError
# introduce(name="小刚", 19, "广州")
```

### 2.4 默认参数（Default Arguments）

定义函数时给参数一个默认值，调用时不传就用默认值。

```python
def greet(name, message="你好"):
    print(f"{name}, {message}")

greet("小明")           # 使用默认值：小明, 你好
greet("小红", "吃了没")  # 覆盖默认值：小红, 吃了没
```

> ⚠️ **坑**：默认参数不要用可变对象（`list`/`dict`/`set`），因为它只会在函数定义时初始化一次。

```python
# ❌ 错误示范：默认参数用 list
def add_item(item, lst=[]):
    lst.append(item)
    return lst

print(add_item(1))   # [1]
print(add_item(2))   # [1, 2]   ← 不是预期的 [2]，上次的列表被复用了

# ✅ 正确写法：默认用 None，函数内部创建新列表
def add_item(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst

print(add_item(1))   # [1]
print(add_item(2))   # [2]   ← 正确
```

## 3. 可变长参数 *args / **kwargs

### 3.1 可变长位置参数 *args

使用 `*` 接收任意数量的**位置参数**，打包成**元组（tuple）**。通常命名为 `*args`（名称只是约定，叫 `*nums` 也行）。

```python
def sum_all(*args):
    print("args:", args)   # 打包成元组
    total = 0
    for num in args:
        total += num
    return total

print(sum_all(1, 2, 3))     # args: (1, 2, 3)      返回 6
print(sum_all(10, 20))      # args: (10, 20)       返回 30
print(sum_all())            # args: ()              返回 0
```

### 3.2 可变长关键字参数 **kwargs

使用 `**` 接收任意数量的**关键字参数**，打包成**字典（dict）**。通常命名为 `**kwargs`。

```python
def show_info(**kwargs):
    print("kwargs:", kwargs)   # 打包成字典
    for key, value in kwargs.items():
        print(f"{key}: {value}")

show_info(name="小明", age=18, city="北京")
# kwargs: {'name': '小明', 'age': 18, 'city': '北京'}
# 输出：
# name: 小明
# age: 18
# city: 北京
```

### 3.3 定义端的参数顺序（严格遵守）

函数**定义**时，必须按以下顺序写：

```
位置参数 → 默认参数 → *args → **kwargs
```

```python
def demo(a, b=10, *args, **kwargs):
    print(f"a={a}, b={b}, args={args}, kwargs={kwargs}")

demo(1, 2, 3, 4, name="test")
# 输出：a=1, b=2, args=(3, 4), kwargs={'name': 'test'}
```

> **说明**：`b=10` 是默认参数，**但前面有位置参数传入时，默认值会被覆盖**。上面的调用里 `1` 传给了 `a`，`2` 传给了 `b`（覆盖了 10），然后 `3, 4` 给了 `*args`，关键字部分给 `**kwargs`。

### 3.4 调用端的解包传参

上面是**定义**端用 `*` / `**` 打包参数。反过来，在**调用**端也可以用 `*` / `**` 把列表 / 字典"展开"成参数传给函数：

```python
def introduce(name, age, city):
    print(f"{name}, {age}岁, 来自{city}")

# 用 * 把列表展开成位置参数
info = ["小李", 22, "成都"]
introduce(*info)   # 等价于 introduce("小李", 22, "成都")
# 输出：小李, 22岁, 来自成都

# 用 ** 把字典展开成关键字参数
info_dict = {"name": "小王", "age": 23, "city": "杭州"}
introduce(**info_dict)   # 等价于 introduce(name="小王", age=23, city="杭州")
# 输出：小王, 23岁, 来自杭州
```

## 4. 匿名函数 lambda

`lambda` 用于写**只有一条表达式的简单函数**，语法紧凑，不能换行，不能写复杂逻辑。

```python
# 语法：lambda 参数1, 参数2, ... : 表达式（表达式的值就是返回值）

# 普通函数
def add(a, b):
    return a + b

# 等价的 lambda 写法
add_lambda = lambda a, b: a + b

print(add(3, 5))          # 8
print(add_lambda(3, 5))   # 8
```

**lambda 典型场景：**配合 `sorted` / `map` / `filter` 当回调。

```python
# 按学生分数排序（sorted 的 key 参数）
students = [("张三", 90), ("李四", 78), ("王五", 95)]
print(sorted(students, key=lambda x: x[1]))
# [('李四', 78), ('张三', 90), ('王五', 95)]   ← 按分数升序

print(sorted(students, key=lambda x: x[1], reverse=True))
# [('王五', 95), ('张三', 90), ('李四', 78)]   ← 降序
```

## 5. 递归 Recursion

### 5.1 什么是递归

**递归**：函数**直接或间接地调用自身**。核心思想是把一个大型、复杂的问题层层转化为一个与原问题相似但规模更小的子问题来解决，直到子问题简单到可以直接得出结果。

### 5.2 递归的三个要素（缺一不可）

1. **基线条件（Base Case）**：问题的最简单形式，此时不再调用自身，直接返回结果（**防止无限循环**）。
2. **递归条件（Recursive Case）**：把原问题分解为更小的子问题，调用自身解决。
3. **逐步逼近**：每次递归调用都必须向基线条件靠近，否则会无限递归，报 `RecursionError`。

### 5.3 经典示例：阶乘

**数学定义**：`n! = n * (n-1) * ... * 1`，且 `0! = 1`、`1! = 1`。

```python
def factorial(n):
    # 1. 基线条件：n 为 1 或 0 时，不再递归
    if n <= 1:
        return 1
    # 2. 递归条件：n! = n * (n-1)!   3. 每次 n-1 → 逐步逼近 n<=1
    return n * factorial(n - 1)

print(factorial(5))   # 120（计算过程：5*4*3*2*1）
print(factorial(0))   # 1
```

执行过程展开：

```
factorial(5)
→ 5 * factorial(4)
→ 5 * (4 * factorial(3))
→ 5 * (4 * (3 * factorial(2)))
→ 5 * (4 * (3 * (2 * factorial(1))))
→ 5 * (4 * (3 * (2 * 1)))          ← 命中基线条件，开始回溯
→ 120
```

### 5.4 经典示例：斐波那契数列

**数学定义**：`F(0)=0`，`F(1)=1`，`F(n) = F(n-1) + F(n-2)`。

```python
def fib(n):
    # 基线条件
    if n == 0: return 0
    if n == 1: return 1
    # 递归条件
    return fib(n - 1) + fib(n - 2)

print(fib(6))   # 8（0, 1, 1, 2, 3, 5, 8 → 第 6 项）
```

> ⚠️ 注意：斐波那契这种写法重复计算多（`fib(3)` 会被算很多次），n 大了非常慢；实际需要记忆化 / 动态规划优化。

## 6. 类型注释 Type Hints

Python 是动态类型，不会强制检查，但加类型注释可以：提升可读性、让 IDE 自动补全、配合静态检查工具（`mypy`）提前发现错误。

### 6.1 变量注释

```python
name: str = "小明"
age: int = 18
score: float = 95.5
is_passed: bool = True
```

### 6.2 函数注释

```python
# 语法：参数名: 类型，-> 返回值类型
def greet(name: str, age: int = 18) -> str:
    return f"{name}今年{age}岁"

print(greet("张三"))       # 张三今年18岁
print(greet("李四", 20))   # 李四今年20岁
```

### 6.3 复杂类型（容器、可选、无返回）

```python
from typing import List, Dict, Tuple, Optional

# List[int] 表示整数列表；Dict[str, int] 表示键字符串值整数的字典
def sum_numbers(nums: List[int]) -> int:
    total = 0
    for n in nums:
        total += n
    return total

print(sum_numbers([1, 2, 3, 4]))   # 10

# Tuple[str, int, bool] 表示固定位置、固定类型的元组
def get_student() -> Tuple[str, int, bool]:
    return ("小明", 18, True)

# Optional[int] 等价于 int | None：可能返回 int，也可能返回 None
def find_user(user_id: int) -> Optional[str]:
    if user_id == 1:
        return "admin"
    return None
```

> **Python 3.10+** 可以直接写 `list[int]`、`dict[str, int]`、`int | None`，不必从 `typing` 导入。

## 7. 函数高级用法

### 7.1 文档字符串 Docstring

`def` 之后第一行的三引号字符串，用于说明函数作用。用 `help(函数名)` 或 `函数名.__doc__` 查看。

```python
def add(a, b):
    """返回两个数的和

    Args:
        a (int): 第一个加数
        b (int): 第二个加数

    Returns:
        int: a + b
    """
    return a + b

help(add)        # 打印完整文档
print(add.__doc__)   # 打印文档字符串内容
```

### 7.2 函数作为参数（高阶函数）

函数可以当参数传给另一个函数。

```python
def apply_op(a, b, op):
    return op(a, b)

def add(x, y): return x + y
def mul(x, y): return x * y

print(apply_op(3, 5, add))   # 8   → 把 add 函数传进去
print(apply_op(3, 5, mul))   # 15  → 把 mul 函数传进去
print(apply_op(3, 5, lambda x, y: x - y))   # -2 → lambda 也行
```

## 8. 作用域 LEGB 规则

变量查找顺序（从内到外）：

| 层级 | 名称 | 说明 |
|------|------|------|
| **L** — Local | 局部作用域 | 函数内部定义的变量 |
| **E** — Enclosing | 闭包外层作用域 | 嵌套函数的外层函数作用域 |
| **G** — Global | 全局作用域 | 模块（.py 文件）顶层定义的变量 |
| **B** — Built-in | 内置作用域 | Python 内置（如 `len` / `print` / `True`） |

### 8.1 基础示例

```python
x = 100              # G — 全局

def outer():
    x = 200          # E — 闭包外层（Enclosing）
    def inner():
        x = 300      # L — 局部（Local）
        print(x)     # 就近取 L 的 300
    inner()
    print(x)         # 取 E 的 200

outer()
print(x)             # 取 G 的 100

# 输出：300 → 200 → 100
```

### 8.2 global — 在函数内修改全局变量

函数内对变量**赋值**默认会把它当成局部变量，想直接修改全局变量需要用 `global`。

```python
count = 0

def increment():
    global count        # 声明 count 用全局的，不要新建局部
    count += 1

increment()
increment()
print(count)   # 2   ← 改到了全局的 count

# ❌ 不加 global 会报错：UnboundLocalError
# def increment_bad():
#     count += 1   # Python 以为 count 是局部变量，但没赋值就用，报错
```

### 8.3 nonlocal — 在嵌套函数内修改外层变量

修改**闭包外层（Enclosing）** 的变量，用 `nonlocal`。

```python
def counter():
    total = 0
    def add_one():
        nonlocal total     # 声明用外层的 total，不要新建局部
        total += 1
        return total
    return add_one

c = counter()
print(c())   # 1
print(c())   # 2
print(c())   # 3
```

> **总结**：`global` 改**模块级别（G）**的变量；`nonlocal` 改**嵌套函数外层（E）**的变量。只读取不改值的话不需要声明。
