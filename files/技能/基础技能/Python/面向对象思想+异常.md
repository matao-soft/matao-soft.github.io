## 1. 面向对象基础

### 1.1 什么是面向对象

**面向对象编程（简称 OOP）** 是一种编程范式（编程思想）：将现实世界中的事物抽象为程序中的"对象"，每个对象都包含 **属性（数据/特征）** 和 **方法（行为/功能）**。

### 1.2 类（Class）与对象（Object）

| 概念 | 说明 | 现实类比 |
|------|------|----------|
| **类（Class）** | 对象的"蓝图"或"模板"，定义属性和方法 | "人类"这个概念 |
| **对象（Object）** | 根据类创建的具体**实例** | 具体的"小明"这个人 |

### 1.3 基本语法

```python
# 定义类（class 关键字，类名用 大驼峰 命名法）
class Student:
    # __init__：构造方法，创建对象时自动调用
    # self 必须写在最前面，代表"当前对象自身"
    def __init__(self, name, age):
        self.name = name     # 实例属性
        self.age = age

    # 实例方法：第一个参数永远是 self
    def introduce(self):
        print(f"我叫{self.name}，今年{self.age}岁")

# 创建对象（实例化）
stu1 = Student("小明", 18)
stu2 = Student("小红", 17)

# 调用对象的方法
stu1.introduce()   # 输出：我叫小明，今年18岁
stu2.introduce()   # 输出：我叫小红，今年17岁

# 访问属性
print(stu1.name)   # 小明
print(stu2.age)    # 17
```

> 命名规范：类名 **大驼峰**（`StudentInfo`）；方法/属性名 **snake_case**（`user_name`）。

## 2. 魔法方法（Dunder Methods）

**魔法方法**：以双下划线 `__` 开头和结尾的特殊方法（如 `__init__`、`__str__`）。**不需要手动调用**，在特定操作或内置函数触发时，**由 Python 自动调用**。

### 2.1 `__init__` — 构造与初始化

- **触发时机**：创建对象时（`类名()` 之后）
- **作用**：初始化对象的属性（设置初始状态），相当于 Java/C++ 的构造函数

```python
class Student:
    def __init__(self, name, age):
        print("__init__ 被调用了")
        self.name = name
        self.age = age

stu = Student("小明", 18)   # 打印：__init__ 被调用了
```

### 2.2 `__str__` — 字符串表示

- **触发时机**：`print()` 打印对象，或 `str()` 转字符串时
- **作用**：返回**用户友好**、易读的描述
- **返回值**：必须是 `str`

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        return f"姓名: {self.name}, 年龄: {self.age}"

p = Person("小明", 18)
print(p)        # 输出：姓名: 小明, 年龄: 18
print(str(p))   # 输出：姓名: 小明, 年龄: 18
```

> 对比 `__repr__`：用于开发者调试（`repr()` / 交互式环境输出）。一般 `__str__` 给用户看，`__repr__` 给开发者看。

### 2.3 `__eq__` — 等于（==）

- **触发时机**：使用 `==` 比较两个对象
- **作用**：自定义对象相等性判断逻辑
- **返回值**：`bool`

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __eq__(self, other):
        # 名字 + 年龄都相同，才认为两个对象相等
        return self.name == other.name and self.age == other.age

p1 = Person("小明", 18)
p2 = Person("小明", 18)
p3 = Person("小红", 17)

print(p1 == p2)   # True（属性一致）
print(p1 == p3)   # False
```

### 2.4 `__lt__` / `__le__` / `__gt__` / `__ge__` — 大小比较

| 方法 | 对应运算符 | 作用 |
|------|-----------|------|
| `__lt__(self, other)` | `<` | 小于 |
| `__le__(self, other)` | `<=` | 小于等于 |
| `__gt__(self, other)` | `>` | 大于 |
| `__ge__(self, other)` | `>=` | 大于等于 |

**用法**：写 `__lt__` + `__eq__`，再加 `@functools.total_ordering` 装饰器，Python 自动补全 `<= / > / >=` 四种比较。

```python
from functools import total_ordering

@total_ordering
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def __lt__(self, other):
        return self.score < other.score   # 按分数升序

    def __eq__(self, other):
        return self.score == other.score


s1 = Student("张三", 90)
s2 = Student("李四", 85)
s3 = Student("王五", 95)

print(s1 < s2)   # False（90 < 85 不成立）
print(s1 >= s1)  # True（total_ordering 自动补全的 >=）

# 配合 sorted 排序
students = [s1, s2, s3]
rank = sorted(students, reverse=True)   # 降序
for s in rank:
    print(f"{s.name}: {s.score}")
# 王五: 95
# 张三: 90
# 李四: 85
```

### 2.5 魔法方法速查表

| 方法 | 触发场景 | 作用 |
|------|----------|------|
| `__len__(self)` | `len(obj)` | 返回长度 |
| `__contains__(self, x)` | `x in obj` | 成员判断 |
| `__getitem__(self, k)` | `obj[k]` | 按下标/键取值 |
| `__setitem__(self, k, v)` | `obj[k] = v` | 按下标/键赋值 |
| `__call__(self, *args)` | `obj()` | 让对象可像函数一样调用 |
| `__del__(self)` | 对象销毁前 | 析构函数，资源清理（少用） |

## 3. 三大核心特性

### 3.1 封装（Encapsulation）

**定义**：将数据（属性）和对数据的操作（方法）打包在一起，**隐藏内部实现细节**，仅对外暴露必要的接口。

**作用**：保护数据安全，防止外部随意修改。

```python
class BankAccount:
    def __init__(self, owner):
        self.owner = owner
        # 双下划线开头的属性 → 私有属性，外部无法直接访问
        self.__balance = 0

    # 提供公共方法（getter / setter）操作私有属性
    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
            print(f"存入 {amount} 元，当前余额 {self.__balance}")

    def withdraw(self, amount):
        if 0 < amount <= self.__balance:
            self.__balance -= amount
            print(f"取出 {amount} 元，当前余额 {self.__balance}")

    # getter：只读
    def get_balance(self):
        return self.__balance


acc = BankAccount("小明")
# print(acc.__balance)   # ❌ 报错：AttributeError，外部无法直接访问
acc.deposit(100)          # 存入 100 元，当前余额 100
acc.withdraw(30)          # 取出 30 元，当前余额 70
print(acc.get_balance())  # 70
```

> ⚠️ 注意：Python 的"私有"只是**名字改写（name mangling）**，不是真正限制访问（可用 `_BankAccount__balance` 绕开）。**`__xx` 是约定**，表达"不希望外部直接用"，技术上能绕开，但遵守约定就好。

### 3.2 继承（Inheritance）

**定义**：子类（派生类）继承父类（基类）的属性和方法，还可以扩展或**重写（覆盖）**父类方法。

**作用**：代码复用、建立层级关系。

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def eat(self):
        print(f"{self.name} 正在吃东西")

# Dog 继承 Animal（括号里写父类名）
class Dog(Animal):
    def bark(self):
        print(f"{self.name} 汪汪叫")

# Cat 继承 Animal，并重写 eat 方法
class Cat(Animal):
    def eat(self):   # 方法重写（Override）
        print(f"{self.name} 优雅地吃鱼")


dog = Dog("旺财")
dog.eat()    # 旺财 正在吃东西（继承父类）
dog.bark()   # 旺财 汪汪叫（自己的方法）

cat = Cat("咪咪")
cat.eat()    # 咪咪 优雅地吃鱼（重写了父类方法）
```

**`isinstance` 判断继承关系**：

```python
print(isinstance(dog, Animal))  # True（子类实例也是父类实例）
print(isinstance(dog, Dog))     # True
print(isinstance(dog, Cat))     # False
```

### 3.3 多态（Polymorphism）

**定义**：不同类的对象对**同一个方法**做出**不同的响应**。"同一个接口，多种实现"。

**作用**：提高程序灵活性和可扩展性——新增同类功能不需要改老代码（开闭原则）。

```python
class Dog(Animal):
    def speak(self):
        print(f"{self.name} 汪汪汪")

class Cat(Animal):
    def speak(self):
        print(f"{self.name} 喵喵喵")

class Duck(Animal):
    def speak(self):
        print(f"{self.name} 嘎嘎嘎")


# 多态核心：不关心具体是什么动物，只要有 speak() 方法就行
def make_sound(animal):
    animal.speak()


make_sound(Dog("旺财"))   # 旺财 汪汪汪
make_sound(Cat("咪咪"))   # 咪咪 喵喵喵
make_sound(Duck("可达鸭")) # 可达鸭 嘎嘎嘎
```

## 4. 继承进阶

### 4.1 `super()` — 调用父类方法

在子类里想调用父类的同名方法（特别是 `__init__`），用 `super()`：

```python
class Animal:
    def __init__(self, name, age):
        self.name = name
        self.age = age

class Student(Animal):
    def __init__(self, name, age, grade):
        # 先让父类初始化 name、age，避免写重复代码
        super().__init__(name, age)
        self.grade = grade   # 子类自己加的属性

    def introduce(self):
        print(f"{self.name}, {self.age}岁, {self.grade}年级")

stu = Student("小明", 18, 3)
stu.introduce()   # 小明, 18岁, 3年级
```

### 4.2 多继承 & MRO

Python 支持**多继承**（一个子类继承多个父类）。方法查找顺序叫 **MRO（Method Resolution Order）**。

```python
class A:
    def hi(self):
        print("A")

class B:
    def hi(self):
        print("B")

class C(A, B):   # 同时继承 A 和 B
    pass

c = C()
c.hi()                 # 输出 A（MRO 顺序从左到右：C → A → B）
print(C.__mro__)       # 查看 MRO 顺序
# (<class 'C'>, <class 'A'>, <class 'B'>, <class 'object'>)
```

> MRO 按**广度优先、从左到右**查找。冲突时靠继承顺序决定，复杂场景建议尽量避免"菱形继承"。

### 4.3 类方法 @classmethod & 静态方法 @staticmethod

| 方法类型 | 装饰器 | 第一个参数 | 典型用途 |
|----------|--------|-----------|----------|
| 实例方法 | 无 | `self`（实例） | 操作实例属性，最常用 |
| 类方法 | `@classmethod` | `cls`（类本身） | 工厂方法、访问类属性、提供多种创建实例的方式 |
| 静态方法 | `@staticmethod` | 无 | 和类相关但不需要 self/cls，本质是个普通函数，只是放在类里面 |

```python
class Person:
    species = "Homo sapiens"   # 类属性（所有实例共享，属于类本身）

    def __init__(self, name, age):
        self.name = name       # 实例属性（每个对象一份）
        self.age = age

    # 实例方法：最常用
    def introduce(self):
        print(f"{self.name} ({self.species})")

    # 类方法：用 cls 操作类本身
    @classmethod
    def from_birth_year(cls, name, birth_year):
        # 工厂方法：用"出生年份"创建实例，而不是传年龄
        age = 2026 - birth_year
        return cls(name, age)

    # 静态方法：不需要 self/cls
    @staticmethod
    def is_adult(age):
        return age >= 18


# 类方法：两种等价的创建方式
p1 = Person("小明", 18)
p2 = Person.from_birth_year("小红", 2005)   # 2026 - 2005 = 21
print(p2.age)   # 21

# 静态方法
print(Person.is_adult(20))   # True
print(Person.is_adult(15))   # False
```

## 5. 异常处理

### 5.1 什么是异常

程序运行时出现的**错误**会导致程序崩溃（Python 会抛出 `Exception`）。**异常处理** 用 `try...except` 捕获并处理这些错误，让程序在出错时能够恢复或给出友好提示。

### 5.2 基本语法

```python
try:
    # 可能抛出异常的代码
    x = int(input("请输入一个整数: "))
    result = 10 / x
    print(f"10 / {x} = {result}")
except ValueError:
    # 捕获「类型转换失败」
    print("❌ 不是有效的整数")
except ZeroDivisionError as e:
    # 捕获「除以 0」，as e 拿到异常对象，打印详情
    print(f"❌ 不能除以 0。错误详情：{e}")
except Exception as e:
    # 兜底：捕获其他所有异常。一般放在最后，避免吞掉不该吞的错误
    print(f"❌ 未知错误：{e}")
else:
    # 没有发生任何异常才执行（可选）
    print("✅ 一切正常，计算成功！")
finally:
    # 无论是否异常都会执行（可选）
    # 常用于清理：关闭文件、释放锁、断开数据库
    print("清理完成")
```

执行顺序：`try → 要么 except 要么 else → 一定 finally`。

### 5.3 常见异常类型

| 异常类型            | 说明       | 触发场景                                     |
| ------------------- | ---------- | -------------------------------------------- |
| `ValueError`        | 值错误     | `int("abc")`（字符串不能转整数）             |
| `TypeError`         | 类型错误   | `"1" + 1`（字符串加整数）                    |
| `IndexError`        | 索引错误   | `[1, 2][5]`（越界）                          |
| `KeyError`          | 键错误     | `{"a": 1}["b"]`（字典键不存在）              |
| `ZeroDivisionError` | 除以零错误 | `1 / 0`                                      |
| `FileNotFoundError` | 文件不存在 | `open("xxx.txt")`                            |
| `AttributeError`    | 属性错误   | `"abc".foo()`（访问不存在的属性/方法）       |
| `ImportError`       | 导入错误   | `import nonexist_module`                     |
| `KeyboardInterrupt` | 用户中断   | 你按了 Ctrl+C                               |
| `StopIteration`     | 迭代终止   | 迭代器没有更多元素                           |

### 5.4 `raise` — 主动抛出异常

校验参数不合法时，主动 `raise` 一个异常：

```python
def divide(a, b):
    if b == 0:
        raise ValueError("除数不能为 0")   # 主动抛
    return a / b

try:
    divide(10, 0)
except ValueError as e:
    print(f"错误：{e}")   # 错误：除数不能为 0
```

### 5.5 自定义异常

继承 `Exception` 就能写自己的异常类：

```python
class InsufficientBalanceError(Exception):
    """余额不足异常"""
    pass

def pay(balance, cost):
    if balance < cost:
        raise InsufficientBalanceError(
            f"余额 {balance} 小于消费 {cost}"
        )
    return balance - cost

try:
    pay(50, 100)
except InsufficientBalanceError as e:
    print(f"支付失败：{e}")
# 支付失败：余额 50 小于消费 100
```

### 5.6 `with` — 上下文管理器（推荐处理文件/资源）

`with` 本质是 `try...finally` 的语法糖，**用完自动清理资源**，避免忘记关文件 / 释放锁。

```python
# 传统写法（容易忘 f.close()）
f = open("test.txt", "r", encoding="utf-8")
try:
    content = f.read()
finally:
    f.close()

# with 写法：自动关闭文件（出块时自动调用 f.close()）
with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()
# 离开 with 块，f 已自动关闭
```

## 6. 附录：类属性 vs 实例属性 + 方法类型总结

### 6.1 类属性 vs 实例属性

```python
class Person:
    species = "人类"            # 类属性：所有对象共享一份，改一次全部生效

    def __init__(self, name):
        self.name = name        # 实例属性：每个对象有自己的一份

p1 = Person("小明")
p2 = Person("小红")

# 改类属性 → 两个都变
Person.species = "智人"
print(p1.species)   # 智人
print(p2.species)   # 智人

# 改实例属性 → 互不影响
p1.name = "大明"
print(p1.name)      # 大明
print(p2.name)      # 小红
```

### 6.2 三种方法一张图对比

```
实例方法   → def f(self, ...)           ← 改 self.xxx，最常用
类方法     → @classmethod def f(cls,...) ← 工厂方法 / 改类属性
静态方法   → @staticmethod def f(...)   ← 和类相关但不用 self/cls
```

### 6.3 快速自查清单

- 所有对象属性都在 `__init__` 里定义 ✅
- 外部不直接访问 `__xxx` 私有属性 ✅
- 继承用 `super().__init__(...)` 调父类构造 ✅
- 大文件 / 数据库 / 网络资源用 `with` ✅
- 捕获异常尽量**精准**（少用裸 `except:`），不要吞异常 ✅
